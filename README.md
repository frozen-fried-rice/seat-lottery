# 席くじ

宴会・懇親会の席をQRコードのくじで決め、1杯目のドリンクを参加者が自分のスマホで登録するアプリです。
幹事は、全員の席とドリンクを一覧で見て、お店への注文と卓ごとの配膳に使えます。

このリポジトリには2つの版があります。

| 版 | 場所 | 特徴 |
|---|---|---|
| **Google Apps Script 版**（おすすめ） | `gas/` | 参加者が自分のスマホでくじ・ドリンク登録。データはGoogleスプレッドシートに保存。インターネットが必要 |
| 旧版（通信なし） | `index.html`・`seat.html` | 幹事の端末1台で動く版。電波が不安な会場向け。説明は `dos/使い方.txt` |

## Google Apps Script 版

### できること
- **くじ**：参加者がQRを読み取り「くじを引く」を押すと、演出のあとに席が決まります（例：A卓 3番）。同じ席が重なることはありません。
- **QRは2種類**：全員共通のQR（ポスター1枚。読み取ったら名簿から名前を選ぶ）と、1人ずつのQR（名前入りカード）。両方同時に使えます。
- **ドリンク**：1杯目のドリンクを各自が選び、締め切るまで変更できます。選んだあとは「LINEで自分に送る」で結果を残せます。
- **卓分け**：「A卓 8」のように卓ごとの席数を設定。幹事画面に卓ごとの杯数と配膳表（印刷可）が出ます。
- **固定席**：来賓などの席を幹事が決めておけます。席の番号を決めた方も、くじの演出のあとにその席が出ます。
- **幹事画面**：集計つきのドリンク一覧（自動更新）、締め切り、名簿の修正、代わりに引く、QRの発行・印刷、CSV保存。

### ファイル
| ファイル | 中身 |
|---|---|
| `gas/Code.gs` | サーバー側の処理（スプレッドシートの読み書き・くじ・ドリンク登録） |
| `gas/Admin.html` | 幹事画面 |
| `gas/Participant.html` | 参加者のスマホ画面 |
| `gas/appsscript.json` | Apps Script の設定（参考。エディタには貼り付けません） |
| `gas/設置手順.txt` | **初めて設置するときの手順（約15分）** |
| `gas/使い方.txt` | 前日の準備・当日の使い方・困ったとき |
| `BUGS.md` | 開発中に見つけて直したバグの一覧 |

### 設置と使い方
1. `gas/設置手順.txt` の手順で、スプレッドシートを作り、`Code.gs`・`Admin.html`・`Participant.html` を Apps Script に貼り付けてデプロイします。
2. `gas/使い方.txt` の手順で、卓・メニュー・名簿を入れ、QRを用意します。

### 新しい版に差し替えるとき
1. Apps Script の3つのファイルを、このリポジトリの `gas/` の中身に貼り替えて保存します。
2. 「デプロイ」→「デプロイを管理」→ 鉛筆の絵 →「バージョン：新バージョン」→「デプロイ」。
   - 「新しいデプロイ」にするとURLが変わり、配ったQRコードが使えなくなります。

### テスト（開発者向け）
Node.js 18 以上が必要です。Google の環境を模した仕組みの上で動かします。
```
node test/gas.test.cjs   # 単体テスト（サーバー処理）
node test/gas-e2e.cjs    # ブラウザでの通しテスト（Playwright と Chromium が必要）
```
旧版のテスト `test/test.cjs` は作成時の作業フォルダ（`work/`・`outputs/`）向けのもので、このリポジトリのままでは動きません。

テストは模擬環境で行っています。本物の Google 上では、設置後に次を一度確かめてください：CSV保存、印刷、コピー、「大きく表示」、ログインしていないスマホから参加者画面が開けること、「LINEで自分に送る」でLINEが開くこと。
